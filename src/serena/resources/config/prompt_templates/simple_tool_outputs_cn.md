    您正在首次查看项目。
    您的任务是收集有关项目的高级信息，这些信息将在以下步骤中保存到记忆文件中。
    这些信息应该足以理解项目的内容，以及开发代码最重要的命令。
    该项目正在系统上开发：{{ system }}。

    您需要识别至少以下信息：
    * 项目的目的
    * 使用的技术栈
    * 使用的代码风格和约定（包括命名、类型提示、文档字符串等）
    * 任务完成时要运行的命令（linting、格式化、测试等）
    * 代码库的大致结构
    * 测试、格式化和 linting 的命令
    * 运行项目入口点的命令
    * 系统的实用命令，例如 `git`、`ls`、`cd`、`grep`、`find` 等。请记住，系统是 {{ system }}，因此命令可能与常规 Unix 系统不同。
    * 是否有任何应了解的特定准则、风格、设计模式等

    此列表并非详尽无遗，如果您认为有相关信息，可以添加更多。

    为此，您需要使用相应的工具获取项目信息。
    只读取必要的文件和目录，以避免将过多数据加载到内存中。
    如果无法从项目本身找到所需的所有内容，则应向用户询问更多信息。

    收集所有信息后，您将使用 `write_memory` 工具（多次调用）将其保存到各种记忆文件中。
    一个特别重要的记忆文件将是 `suggested_commands.md` 文件，其中应包含用户在此项目中开发代码应了解的命令列表。
    此外，您应该为风格和约定创建记忆文件，并为任务完成时应做什么创建专用记忆文件。
    **重要提示**：完成入职任务后，请记住调用 `write_memory` 保存收集到的信息！
